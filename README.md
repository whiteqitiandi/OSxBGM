# OSxBGM — 台詞 × 背景音樂 融合器

把從電影剪出來的短台詞 mp3（裡面夾雜著背景音樂與特效音）自動對齊到完整的背景音樂，
再無縫融合進去，聽起來就像整首背景音樂播到某個時間點突然出現了人聲。
程式會顯示每個剪輯是從背景音樂的 **哪個時間點** 插入的。

## 技術選擇

| 項目 | 選擇 | 理由 |
|---|---|---|
| 語言 | Python 3.9+ | 音訊/數值生態最成熟、最容易改 |
| GUI | Tkinter（Python 內建） | 不用額外安裝、PyInstaller 打包成單一 exe 最簡單 |
| 數值 | numpy、scipy | 對齊與混音全部用 FFT 互相關完成 |
| 解碼/編碼 | ffmpeg 執行檔 | 支援 mp3/wav/flac/m4a… 任何格式 |

## 安裝與執行

```bat
pip install numpy scipy
```

ffmpeg：已有的話（例如 `C:\ffmpeg64\bin\ffmpeg.exe`）在 `OSxBGM.ini` 填路徑，或在程式介面
「ffmpeg 路徑」欄位瀏覽選取（會自動存到 ini）、按「測試」確認。沒有的話到
<https://www.gyan.dev/ffmpeg/builds/> 下載 `ffmpeg-release-essentials.zip`，取出 `bin\ffmpeg.exe`。

```ini
; OSxBGM.ini（與 OSxBGM.exe / app.py 同資料夾）
[ffmpeg]
ffmpeg = C:\ffmpeg64\bin\ffmpeg.exe
```

尋找順序：ini 指定路徑 → 程式所在資料夾 → exe 內嵌 → 系統 PATH。
若程式啟動失敗，同資料夾會產生 `OSxBGM_error.log`，把內容貼給我即可。

```bat
python app.py          :: 圖形介面
python cli.py 台詞.mp3 背景音樂.mp3      :: 命令列（單一剪輯）
python cli.py 台詞1.mp3 台詞2.mp3 台詞3.mp3 背景音樂.mp3 --ordered --merge-all   :: 多個剪輯，最後一個是背景音樂
```

### 圖形介面操作

1. **輸入 1**：按「加入…」選一個或多個台詞剪輯，長度不限（只要全部加起來放得進背景音樂）。
2. **輸入 2**：選完整背景音樂。
3. 輸出資料夾預設為背景音樂所在資料夾；可選 mp3 / wav / flac。
4. 按「▶ 開始對齊並融合」。結果表會列出每個剪輯的 **插入點（分:秒.毫秒 與 秒數）**、
   結束時間、**吻合**（剪輯裡有幾秒真的來自這首歌）、粗搜尋信心、剪輯內 BGM 相對原曲的音量。
   雙擊結果列可直接播放。
5. 勾選「把所有剪輯合併進同一個輸出檔」可以把一部電影的多句台詞全部放回同一首歌。
6. 勾選「強制依清單順序」：你確定各台詞在歌裡的先後順序時勾選，程式會在每個剪輯的
   候選位置中挑一組「順序與清單相同、彼此不重疊」且總吻合秒數最高的組合，可排除誤判；
   放不進去的剪輯會先問你怎麼辦，不會硬塞。
7. 兩個輸出選項預設都勾選；所有參數（融合方式、人聲 dB、淡化、格式、速度、兩個勾選）
   會在按下開始時存進 `OSxBGM.ini`，下次開啟沿用。
8. 對齊結果有異常時（吻合不到一半、起點在歌曲開始前、結尾超出歌曲、找不到位置、
   依順序放不進去）會在混音前跳出對話框，每個剪輯可選：**完整保留**（起點可能為負、
   輸出檔會變長）、**只保留吻合的部分**、**跳過這個 OS**、**忽略順序放在最佳位置**，或**放棄全部**。
   命令列版在互動模式下以文字詢問，重導向時採預設（完整保留 / 跳過）。

### 參數

- **保持原曲音量（預設）**：音樂全程維持原本音量；剪輯會整體放大到它裡面的
  BGM 與原曲同音量，人聲因此保有電影原本的人聲/音樂比例。剪輯裡的音樂淡入淡出或空白時，
  原曲會自動補滿，不會出現音量凹陷。
- **電影式壓低**：剪輯原樣放入，台詞期間音樂像電影裡一樣變小聲；剪輯淡出/空白處補回原曲到壓低後的音量。
- **人聲音量微調**：預設 −3 dB（電影台詞相對音樂通常很大聲）。保持原曲音量模式下，
  負值會混回部分原曲讓人聲相對變小。
- **交叉淡化**：剪輯兩端的等功率淡入淡出，預設 150 ms。
- **手動指定起點**：自動對齊失敗時填入秒數，程式仍會在 ±5 ms 內自動微調到取樣點精度。
- **剪輯速度倍率**：影片若來自 PAL（25 fps）轉檔，音樂會比原曲快 4.17 %，填 `1.04167`。
  留 1 時程式會自動偵測線性漂移與 PAL 25/24、24/25 兩種常見倍率。

## 演算法

1. 兩個檔案解碼成 44.1 kHz 立體聲；粗搜尋用 22.05 kHz 單聲道。
2. **GCC-ρ 加權相位相關**（ρ = 0.75，限制 120–7000 Hz）在整首背景音樂上搜尋剪輯，取前幾名峰值
   當候選；允許剪輯比歌早開始或超出歌尾（至少重疊 4 秒）。FFT 長度隨剪輯長度自動放大，剪輯長度不限。
3. **逐段驗證**：每 0.5 秒取 1 秒視窗，在候選位置 ±20 ms 內做波形互相關。真的來自這首歌的視窗，
   峰值位置會跟主位置一致（±8 取樣點）；不是的視窗峰值位置是隨機的。由此得到「吻合」遮罩與秒數，
   不怕人聲大聲、也不需要音量門檻。候選以吻合秒數排名。
4. 吻合比例不到一半時改用**分段搜尋**：剪輯切成 4 秒視窗各自在整首歌上搜尋，位置一致的視窗聚成一群，
   對付電影把音樂剪接過（剪輯只有一部分來自這首歌）或剪輯超出歌頭歌尾的情況。
5. 用吻合視窗的峰值做拋物線內插，精修到**取樣點以下**，再以 FFT 相位平移把剪輯對到小數取樣點，
   混音時不會產生梳狀濾波。若吻合視窗的峰值位置呈線性漂移（剪輯與原曲速度略異），
   算出倍率校正後重做；幾乎完全找不到時再嘗試 PAL 25/24 與 24/25。
6. 混音：以 0.4 秒視窗持續估計剪輯裡 BGM 相對原曲的比例 g(t)。保持原曲音量模式輸出 =
   (1 − k·g(t))·原曲 + k·剪輯，BGM 成分總和恆為原曲音量——剪輯的音樂淡出或空白時原曲自動補上。
   剪輯中不吻合的部分只播剪輯本身、原曲暫時靜音，避免兩段音樂打架；兩端等功率交叉淡化；
   最後過一個 30 ms 前瞻峰值限幅器避免爆音。
7. 多個剪輯時，「強制依清單順序」以動態規劃在各剪輯的候選中挑出順序正確、不重疊、總吻合秒數最高的組合。

限制：剪輯裡「不是這首歌」的部分（電影剪接過的音樂、別首曲子）無法把人聲單獨抽出來，只能原樣播放。

## 打包成單一 exe（release\OSxBGM.exe）

雙擊 `build.bat` 即可，全自動：

1. 檢查 Python（需 3.9 以上並已加入 PATH）
2. `pip install numpy scipy pyinstaller`
3. 自動下載 ffmpeg（gyan.dev，失敗則改抓 GitHub BtbN）並取出 `ffmpeg.exe`（只需一次）
4. PyInstaller 打包，ffmpeg.exe 內嵌進 exe
5. 產出 `release\OSxBGM.exe` 與 `release\README.md`，並自動開啟 release 資料夾

產出的 exe 約 100–150 MB，複製到任何 Windows 10/11 電腦即可執行，不需安裝 Python 或 ffmpeg。
第一次啟動會解壓到暫存資料夾，約需 3–5 秒。若資料夾內有 `icon.ico` 會自動當作程式圖示。
